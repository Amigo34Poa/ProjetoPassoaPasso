Na página de um ZIP no GitHub, use a opção de baixar o arquivo bruto (Download raw file). O pacote inclui os runtimes necessários, sem instalá-los no Windows.

Extraia todo o ZIP e abra `Playbook Studio.exe`. Para atualizar, encerre a versão anterior antes de abrir a nova. Leia o arquivo LEIA-ME.txt incluído no pacote.

O fluxo web foi testado. A execução e a captura nativa ainda precisam de validação no Windows 11 da empresa. Transcrição depende de um reconhecedor disponível ou de uma API configurada. O assistente de organização local não exige API.

Atualização 0.2.1: marca-texto translúcido com limites de acessibilidade no Windows, preservação da imagem anterior à navegação e remoção dos botões de gerar GIF/clipe. Consulte os avisos de execução e atualização no LEIA-ME.txt.
